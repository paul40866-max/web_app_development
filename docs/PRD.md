# SmartFridge 智慧食材管家系統 PRD (Product Requirements Document)

## 1. 專案概述

### 背景與動機
在現代忙碌的生活節奏中，許多人常常忘記冰箱裡還有什麼食材，導致食物過期浪費，或者在採買時重複購買。同時，面對冰箱中剩餘的食材，使用者也經常不知道該如何搭配烹調。為了解決這些問題並推廣環保不浪費的理念，我們希望打造一款能夠自動化管理食材、預防剩食並提供烹飪靈感的智慧管家系統。

### 目標用戶
- **忙碌的上班族**：時間有限，需要快速了解庫存狀況與簡單的料理建議。
- **注重飲食健康的家庭主婦**：重視食材新鮮度，需要有效管理家中大量食材。
- **希望減少剩食浪費的環保人士**：關注食物保存期限，期望最大化利用每一份食材。

### 核心價值主張
透過整合影像辨識與 AI 技術，無痛記錄食材入庫與效期，並依據現有庫存推薦客製化食譜，幫助使用者省時、省錢，同時減少食物浪費。

---

## 2. 功能需求

### 主要功能與使用者故事

1. **影像辨識入庫**
   - **使用者故事**：作為一名忙碌的上班族，我希望能夠透過手機拍照自動辨識並記錄購買的食材，以便省去手動輸入的時間與麻煩。

2. **庫存狀態監控**
   - **使用者故事**：作為一名注重飲食健康的家庭主婦，我希望能夠隨時在 App 上查看目前冰箱裡所有食材的清單與剩餘量，以便掌握家中存糧狀態。

3. **智慧過期預警**
   - **使用者故事**：作為一名希望減少剩食浪費的環保人士，我希望系統能在食材即將過期前發送推播通知，以便我能及時將其烹調食用，避免浪費。

4. **AI 剩食食譜推薦**
   - **使用者故事**：作為一名忙碌的上班族，我希望系統能根據我冰箱裡快要過期或剩餘的食材推薦適合的食譜，以便我下班後能快速決定晚餐菜色。

5. **購物清單自動生成**
   - **使用者故事**：作為一名注重飲食健康的家庭主婦，我希望系統能根據我的常用食材消耗情況或想做的食譜自動生成購物清單，以便我在超市採買時不會遺漏或多買。

---

## 3. 非功能需求

### 技術限制
- **後端框架**：Flask (Python)
- **前端技術**：Jinja2 模板引擎 + HTML/CSS/JavaScript
- **資料庫**：SQLite (適合初期 MVP 快速開發與單機儲存)
- **AI/API 整合**：需串接第三方影像辨識 API 與食譜生成 AI 模型。

### 效能與安全考量
- **效能**：影像辨識需在合理時間內（如 3-5 秒）回傳結果；首頁載入食材清單需在 1 秒內完成。
- **安全**：使用者個人資料與庫存紀錄需進行基本的身份驗證與授權保護；密碼需加密儲存。

## 4. MVP 範圍 (Minimum Viable Product)

| 優先級 | 功能名稱 | 說明 |
| --- | --- | --- |
| **Must Have** (核心必備) | 庫存狀態監控 | 提供基本的 CRUD 操作，可手動新增、修改、刪除食材及其到期日。 |
| **Must Have** (核心必備) | 智慧過期預警 | 系統能標示或提醒即將過期（如三天內）的食材。 |
| **Should Have** (應該具備) | AI 剩食食譜推薦 | 根據勾選的現有食材，呼叫 AI API 提供簡單的食譜建議。 |
| **Nice to Have** (未來擴充) | 影像辨識入庫 | 支援上傳照片自動解析食材名稱與數量（初期若無資源可先以手動為主）。 |
| **Nice to Have** (未來擴充) | 購物清單自動生成 | 依據庫存低於安全存量時，自動推播或產生採買清單。 |
